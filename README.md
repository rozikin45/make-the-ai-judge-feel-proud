A tiny program that writes one short family scene — warm, funny and heartfelt — the kind of small domestic moment that would make a proud judge smile.

## Run it

```sh
node main.ts
```

It writes exactly two lines (216 characters, no trailing newline) to `/output/entry.txt`, deterministically — the same bytes on every run.
